# YouTube Cooking Video Controller

YouTube の料理動画を、調理中に操作しやすくするための Web アプリケーションです。

料理中は両手が塞がりやすく、動画が先に進んでしまってもすぐに停止や巻き戻しができません。このアプリでは、YouTube 動画を読み込み、音声操作、大きな操作ボタン、自動停止、ブックマークで調理中の視聴を支援します。

## 主な機能

- YouTube URL を貼り付けて動画を読み込み
- 再生、停止、10秒戻し、30秒戻し
- 日本語音声コマンドによる操作
- 15秒、30秒、60秒ごとの自動停止
- 現在時刻のブックマーク保存
- ブックマーク地点への移動
- 設定とブックマークの localStorage 保存
- スマートフォン、タブレット、デスクトップ対応のレスポンシブ UI

## 使い方

1. アプリを開きます。
2. `YouTube URL` 欄に料理動画の URL を貼り付けます。
3. `読み込む` を押します。
4. 動画が表示されたら、画面下部の操作ボタンで再生、停止、巻き戻しを行います。
5. 音声操作を使う場合は、`音声` ボタンを押して ON にします。
6. ブラウザからマイクの許可を求められたら許可します。
7. 調理中に「止めて」「再生」「10秒戻して」などと話して操作します。

## 音声コマンド

| 話す言葉の例 | 動作 |
| --- | --- |
| 止めて / ストップ / 一時停止 | 動画を一時停止 |
| 再生 / 続けて | 動画を再生 |
| 10秒戻して | 10秒巻き戻し |
| 30秒戻して | 30秒巻き戻し |
| 少し戻して | 10秒巻き戻し |
| もう一回 | 10秒戻して再生 |
| 保存 / ここを保存 | 現在時刻をブックマーク |
| 前の手順 | 直前のブックマークへ移動 |

## 音声操作の注意点

音声認識にはブラウザの Web Speech API を使っています。環境によって動作に差があります。

- Chrome または Edge の最新版を推奨します。
- 音声操作は HTTPS または `localhost` で開いた場合に動作します。
- スマートフォンから `http://192.168...` や `http://172...` のような LAN URL で開くと、マイク API が使えない場合があります。
- 初回利用時はブラウザのマイク許可が必要です。
- 換気扇、水音、調理音が大きい場合は認識精度が落ちます。
- 音声操作が効きにくい場合でも、画面の大きな操作ボタンから同じ操作ができます。

## 自動停止

`自動停止` を ON にすると、動画の再生中に指定した間隔で自動的に一時停止します。

選べる間隔:

- 15秒
- 30秒
- 60秒

料理中に動画が先へ進みすぎるのを防ぎたい場合は、30秒または60秒から試すのがおすすめです。

## ブックマーク

`保存` ボタン、または音声コマンドの「保存」「ここを保存」で、現在の再生時刻をブックマークできます。

ブックマークは動画ごとに保存されます。保存したブックマークを押すと、その時刻へ移動します。不要なブックマークは削除ボタンで消せます。

## 開発環境

必要なもの:

- Node.js 24 以上
- npm

セットアップ:

```bash
npm install
```

開発サーバー起動:

```bash
npm run dev
```

表示された URL をブラウザで開きます。通常は次のような URL です。

```text
http://localhost:5173/
```

すでにポートが使われている場合は、Vite が別のポートを自動で使います。

## テスト

ユニットテスト:

```bash
npm test
```

ビルド:

```bash
npm run build
```
