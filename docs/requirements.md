# 要件定義書

## 1. 背景

YouTube の料理動画を見ながら調理する場合、両手が食材や調理器具で塞がり、動画を一時停止したり巻き戻したりするために手を洗う必要がある。結果として、動画が先に進みすぎる、必要な手順を見逃す、調理の流れが中断されるという課題がある。

本アプリケーションは、YouTube レシピ動画を料理中に扱いやすくするための Web プレイヤーである。音声操作、大きな操作 UI、自動一時停止、手順ブックマークにより、キッチン環境での動画視聴を支援する。

## 2. 目的

- 手が塞がっていても YouTube 料理動画を停止、再生、巻き戻しできるようにする
- 動画が勝手に先へ進みすぎることを防ぐ
- よく戻る調理手順に素早く戻れるようにする
- PC、タブレット、スマートフォンのブラウザで使える MVP を短期間で構築する

## 3. 想定ユーザー

- YouTube の料理動画を見ながら自宅で調理するユーザー
- スマートフォンまたはタブレットをキッチンに置いて動画を見るユーザー
- 動画の一時停止や巻き戻しのために、調理中に画面へ触ることを避けたいユーザー

## 4. 利用シーン

1. ユーザーが YouTube の料理動画 URL をアプリに貼り付ける
2. アプリ内に YouTube プレイヤーが表示される
3. ユーザーは料理しながら動画を視聴する
4. 必要に応じて「止めて」「再生」「10秒戻して」などの音声コマンドで操作する
5. 音声認識が難しい場合は、画面下部の大きなボタンで操作する
6. 自動一時停止モードを使うと、指定秒数ごとに動画が止まる
7. 重要な手順はブックマークとして保存し、後から戻れる

## 5. MVP スコープ

### 5.1 必須機能

- YouTube URL 入力
- YouTube 動画 ID の抽出
- YouTube IFrame Player API による動画表示
- 再生、一時停止、10秒戻し、30秒戻し
- 音声操作の ON/OFF
- 日本語音声コマンドの認識
- 自動一時停止モード
- 一時停止間隔の選択
- 現在時刻のブックマーク保存
- ブックマーク一覧表示
- ブックマーク地点へのシーク
- ブラウザ localStorage への設定とブックマーク保存
- スマートフォン、タブレット、デスクトップに対応するレスポンシブ UI

### 5.2 MVP で対応する音声コマンド

| コマンド例 | 動作 |
| --- | --- |
| 止めて / ストップ / 一時停止 | 動画を一時停止する |
| 再生 / 続けて | 動画を再生する |
| 10秒戻して / 少し戻して | 10秒巻き戻す |
| 30秒戻して | 30秒巻き戻す |
| もう一回 | 10秒巻き戻して再生する |
| 保存 / ここを保存 | 現在時刻をブックマークする |
| 前の手順 | 直前のブックマークへ戻る |

### 5.3 MVP では扱わない機能

- YouTube Data API による動画検索
- ユーザーアカウント
- クラウド同期
- レシピ本文の自動抽出
- 動画の字幕解析
- AI による手順分割
- ネイティブモバイルアプリ
- YouTube 以外の動画プラットフォーム

## 6. 機能要件

### 6.1 動画読み込み

- ユーザーは YouTube の通常 URL、短縮 URL、埋め込み URL を入力できる
- アプリは URL から動画 ID を抽出する
- 有効な動画 ID が取得できた場合、プレイヤーを表示する
- 無効な URL の場合、ユーザーにエラーを表示する

### 6.2 プレイヤー操作

- 再生ボタンで動画を再生できる
- 一時停止ボタンで動画を停止できる
- 巻き戻しボタンで現在時刻から 10秒または 30秒戻せる
- シーク先は 0秒未満にならない
- 一時停止時に任意で 3秒戻して停止する設定を将来的に追加できる設計にする

### 6.3 音声操作

- ユーザーは明示的に音声操作を開始、停止できる
- 音声認識が利用できないブラウザでは、利用不可であることを表示する
- 認識したテキストをコマンドにマッピングしてプレイヤー操作を実行する
- 誤認識に備え、音声操作なしでもすべての主要操作を UI から実行できる

### 6.4 自動一時停止

- ユーザーは自動一時停止を ON/OFF できる
- 一時停止間隔は 15秒、30秒、60秒から選択できる
- ON の間、動画再生中に指定秒数が経過したら自動で一時停止する
- ユーザーが再生を再開したら、次の間隔計測を開始する

### 6.5 ブックマーク

- ユーザーは現在の再生時刻をブックマーク保存できる
- ブックマークには時刻、ラベル、作成日時を持たせる
- 初期ラベルは `手順 1` のように自動採番する
- ブックマークをクリックすると、その時刻へ移動する
- ブックマークは動画 ID ごとに localStorage へ保存する
- ブックマークは削除できる

### 6.6 設定保存

- 最後に開いた動画 URL
- 音声操作の有効状態
- 自動一時停止の有効状態
- 自動一時停止の間隔
- ブックマーク一覧

上記を localStorage に保存する。

## 7. 非機能要件

### 7.1 対応ブラウザ

- 優先対応: Google Chrome 最新版、Microsoft Edge 最新版
- 準対応: Safari 最新版、Firefox 最新版
- SpeechRecognition はブラウザ差があるため、非対応ブラウザではタッチ UI を主導線とする

### 7.2 対応デバイス

- スマートフォン
- タブレット
- デスクトップ

キッチン利用を主目的とするため、タブレット横置きとスマートフォン縦置きを特に重視する。

### 7.3 ユーザビリティ

- 主要操作ボタンは押し間違いを避けられる大きさにする
- 操作パネルは動画視聴を妨げない位置に固定する
- 調理中に読めるよう、文字サイズとコントラストを十分に確保する
- 音声操作の状態が一目で分かるようにする
- エラー文言は短く具体的にする

### 7.4 パフォーマンス

- 初回表示は軽量に保つ
- YouTube IFrame API は必要時にロードする
- 状態更新のためのタイマーは 500ms から 1000ms 程度に抑える
- 不要な再レンダリングを避ける

### 7.5 セキュリティ・プライバシー

- MVP ではサーバーへ個人データを送信しない
- 保存データはブラウザ localStorage のみに保持する
- 音声認識はブラウザ実装に依存し、利用開始前にユーザー操作を必須とする
- YouTube 埋め込みは公式 IFrame Player API を利用する

## 8. 技術スタック

### 8.1 採用技術

| 領域 | 技術 | 理由 |
| --- | --- | --- |
| アプリ基盤 | Vite | 軽量で起動が速く、MVP に適している |
| UI | React | 状態を持つ動画操作 UI と相性が良い |
| 言語 | TypeScript | YouTube Player API や音声認識 API の扱いを型で補助できる |
| スタイリング | CSS Modules または通常 CSS | 小規模 MVP では Tailwind 等を必須にしない方が単純 |
| 動画制御 | YouTube IFrame Player API | YouTube 動画を公式に制御できる |
| 音声認識 | Web Speech API | ブラウザで音声操作を実装できる |
| 永続化 | localStorage | MVP ではサーバー不要で十分 |
| テスト | Vitest / Testing Library | URL パースやコマンド解釈など純粋ロジックを検証しやすい |
| E2E | Playwright | 実ブラウザでレスポンシブ UI と基本操作を確認できる |

### 8.2 Next.js を採用しない理由

本アプリは MVP 時点ではサーバーサイドレンダリング、API Routes、認証、ルーティングの複雑さを必要としない。YouTube IFrame Player API と Web Speech API はブラウザ実行が中心であり、Vite + React の方が構成が単純で開発速度が高い。

将来的にアカウント、クラウド同期、レシピ共有、SEO が必要になった段階で Next.js への移行を検討する。

## 9. 制約

- YouTube の仕様上、動画によっては埋め込み再生が許可されていない場合がある
- Web Speech API の音声認識はブラウザや OS により動作差がある
- キッチン環境の騒音により音声認識精度が落ちる可能性がある
- モバイルブラウザでは自動再生や音声認識開始にユーザー操作が必要な場合がある

## 10. 成功基準

- YouTube URL を入力して動画を再生できる
- 料理中の主要操作である停止、再生、巻き戻しを大きな UI から実行できる
- Chrome 系ブラウザで基本的な日本語音声コマンドが動作する
- 自動一時停止により動画が先に進みすぎる問題を軽減できる
- ブックマークにより重要な手順へ戻れる
- スマートフォンとタブレットで破綻しない UI になっている
